## Analisis Keuntungan Compose Dibandingkan XML Layout

1. Kode lebih ringkas. UI ditulis langsung dalam Kotlin tanpa file XML terpisah,
   findViewById, atau ViewBinding, sehingga boilerplate berkurang.
2. UI deklaratif. Programmer cukup menyatakan tampilan yang diinginkan, dan
   tampilan otomatis berubah mengikuti state (recomposition), tidak perlu mengubah
   properti view secara manual.
3. Mudah dipelihara dan dipakai ulang. Komponen berupa fungsi Composable yang
   modular, dan logika serta tampilan berada di satu tempat sehingga risiko
   ketidaksinkronan UI dan data lebih kecil.
4. Produktivitas lebih tinggi. Fitur Preview dan Modifier yang bisa dirangkai
   mempercepat pembuatan dan penyesuaian tampilan.
